# Security Policy

## Supported versions

Security fixes are applied to the current `master` branch and the latest GitHub Pages production deploy.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub’s [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-advising-on-vulnerabilities/privately-reporting-a-security-vulnerability) on this repository (Security → Report a vulnerability). Do not open a public issue for security reports.

## Trust model

Harada Canvas is a local-first client app. Square contents are stored in the browser via `localStorage`. There is no server-side user data or networked persistence in the application itself.
